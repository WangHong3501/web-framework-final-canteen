# 页面开发 A 实际验收记录

验收日期：2026-11-13。负责人：王鸿（32605150621）。范围为学生/商家登录、会话与全局权限守卫，以及个人中心四个嵌套子页面。以下为本机实际执行结果，不把其他成员的接入入口算成已完成业务。

## 环境与复现

Node.js `v22.23.2`；npm `10.9.8`；Vue `3.5.45`；Vue Router `4.6.4`；Pinia `3.0.4`；persist 插件 `4.7.1`；Element Plus `2.14.8`；Axios `1.21.1`；GSAP `3.15.1`；Vite `8.3.8`；json-server `0.17.4`；Playwright `1.65.0`；axe 集成 `4.14.0`；Prettier `3.10.1`。依赖以提交的 lock 文件复现。

在 `web/` 下运行：

```cmd
npm ci
npm test
npm run test:e2e
npm run build
npm run test:preview
npm run format:check
npm audit --registry=https://registry.npmjs.org
```

本机默认 npm 全局入口存在路径异常，执行工具时使用 Node 安装目录旁的 npm CLI，等价命令示例：

```cmd
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" run build
```

无全局 npm 异常的成员直接使用普通命令。Windows 一键启动文件也直接调用随 Node 安装的 npm，不改动全局配置。浏览器验收采用已安装的 Chrome；模拟数据库均独立放在忽略提交的 `.local/` 下。

## 功能与边界用例

| 编号 | 操作 | 预期与实际 |
| --- | --- | --- |
| A01 | 空账号/密码提交 | 表单提示必填，停留登录页；通过 |
| A02 | 错误密码或学生冒充商家 | 服务端 401，无会话；清楚提示身份/凭据错误；通过 |
| A03 | 未登录直达 `/center/profile` | 守卫跳转登录并携带来源，登录后回到个人资料；通过 |
| A04 | 登录后刷新、直达子路由 | 重新核验服务端会话，正确渲染嵌套页面；通过 |
| A05 | 改昵称并保存、刷新 | PUT 成功后重新 GET，刷新仍读到保存值；通过 |
| A06 | 保存口味偏好、刷新 | 服务器与控件状态一致；未保存时离开有确认；通过 |
| A07 | 学生直达 `/admin/dishes` | 到无权限页面，商家身份可访问自己的入口；通过 |
| A08 | 伪造 token、过期 token、退出后的 token | 不能恢复账户，服务端 401；通过 |
| A09 | 登录 redirect 指向外站 | 回到个人概览，不跳出本站；通过 |
| A10 | 修改 role/id 等受限字段，或填非法手机号/偏好 | 422 或 403，不写入错误值；通过 |
| A11 | 查询其他用户订单、读取 `/users` 或 `/db` | 不返回他人订单或原始用户库；通过 |
| A12 | 修改密码 | 原密码验证、新密码规则、全部旧会话失效，新密码可登录；通过 |
| A13 | API 中断 | 登录显示可重试错误；已登录恢复失败不擅自删除有效本地会话，恢复服务后可重试；通过 |
| A14 | 勾选保持登录、打开新标签页 | 使用 localStorage，新的页面经服务端核验恢复；通过 |
| A15 | 375px 手机与 768px 平板 | 无横向溢出，减少动效模式仍可登录与导航；通过 |
| A16 | 上海时区凌晨/早晨/中午/下午/夜晚 | 问候和图标正确，不受“时”字或主机时区影响；5 个固定时刻通过 |
| A17 | 推进浏览器时间至登录有效期之后 | 路由立即清理本地会话并返回登录，不依赖缓存 getter；通过 |
