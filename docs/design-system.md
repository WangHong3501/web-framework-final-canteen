# 食光食堂 · 全局设计系统与业务组件规范

> 负责人：王鸿（32605150621）
> 目标：完全脱离组件库原生风格，建立食堂专属设计系统；Element Plus 与 Vant 仅作为渲染载体，双端视觉语言、交互逻辑、业务语义 100% 统一。

## 1. 架构分层（单向依赖）

```
styles/
├── tokens.css      # 0-tokens：设计令牌，唯一真相源（纯变量）
├── global.css      # 1-reset / 2-base：全局重置、通用工具类与基础业务样式
├── overrides.css   # 3-overrides：Element Plus / Vant 组件覆盖（集中管理）
└── 组件 scoped 样式  # 4-business：业务组件样式随组件封装，零全局污染
```

- 业务页面只允许引用令牌变量，禁止硬编码色值 / 字号 / 间距 / 圆角 / 阴影 / 动效时长。
- 组件库差异修正全部集中在 `overrides.css`，不散落到业务页面。

## 2. 设计令牌（tokens.css）

| 类别 | 规则 |
| --- | --- |
| 品牌色阶 | 森林绿 10 档 `--brand-50 ~ 900`；主色 700（#234b36）、hover 600、深色 800/900 |
| 中性色阶 | 绿灰 10 档 `--gray-50 ~ 900`：标题 700 / 正文 600 / 辅助 500 / 占位 400 / 边框 200 / 页面背景 50 / 卡片纯白 |
| 功能色阶 | success / warning / danger / info 各含 600 文本色、100 浅底、line 描边 |
| 食堂语义色 | 招牌 / 新品 / 售罄 / 辣度 / 素食 / 清真，语义→色值→标签样式全局复用 |
| 排版 | 字号阶梯 10~36 共 11 档；字重仅 400 / 500 / 600；行高 1.3 / 1.5 / 1.4 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48（8px 基准 + 4px 补充） |
| 圆角 | 4（小标签）/ 8 / 10（控件）/ 12（卡片）/ 16（大卡片）/ 20（弹窗）/ 胶囊 |
| 阴影 | 四档 `--shadow-1 ~ 4`，统一中性透明值 |
| 动效 | 150 / 200 / 300ms 三档，缓动统一 `--ease-out`，禁用弹跳动画 |
| 层级 | 6 层 z-index：内容 < 浮起 < 下拉 < 弹窗 < 遮罩 < 全局提示 |
| 组件库映射 | `--el-*` 与 `--van-*` 全量映射同一套色阶 / 圆角 / 字号 / 动效，双端像素级一致 |

无障碍：正文对比度满足 WCAG 2.1 AA；状态信息同时使用颜色 + 文字 + 图标三重标识（如售罄 = 灰度图 + 遮罩文案 + 禁用图标）。

## 3. 组件覆盖层（overrides.css）

- Element Plus：按钮（含 hover / active / focus / disabled / loading）、输入与选择器（focus 高亮、错误红框、禁用态）、弹层（遮罩、弹窗圆角阴影、Message 语义底色）、表单控件（checkbox / radio / switch / tag）、菜单、表格与骨架屏。
- Vant：按钮、标签、Toast、Dialog、Card 等变量与细节修正；移动端页面接入后自动生效。

## 4. 业务组件（src/components/ui）

| 组件 | 职责 | 关键 Props |
| --- | --- | --- |
| `StatusTag.vue` | 业务状态标签（可点餐 / 余量少 / 已售罄 / 招牌 / 新品 / 辣度 / 素食 / 清真） | `type` `text` `size` `dot` |
| `PriceTag.vue` | 价格规范：符号 + 整数 + 小数分离字重；列表 / 辅助 / 划线原价 / 折扣徽章 / 详情大价 | `value` `original` `variant` `size` |
| `FoodCard.vue` | 菜品卡片：4:3 图片、招牌 / 新品角标、售罄灰度 + 遮罩、辣度与饮食标签、价格 + 操作插槽 | `food`，插槽 `action` |
| `OrderStatusFlow.vue` | 订单状态流：待支付 → 待备餐 → 待取餐 → 已完成，退款终态；桌面横向 / 移动纵向 | `status` `compact` |
| `PickupCode.vue` | 取餐码：大字号等宽数字 + 取餐窗口 / 预计时间辅助信息 | `code` `window` `eta` |
| `MealSwitch.vue` | 餐次切换（早 / 午 / 晚 / 夜宵），含禁用态与移动端 44px 触控适配 | `modelValue` `disabledKeys` |
| `EmptyState.vue` | 空状态：统一插图风格 + 「说明 + 引导操作」文案结构 | `title` `detail` `actionLabel` `icon` |

双端适配原则：同一组件信息结构与语义不变，仅在 ≤680px 时调整密度（状态流改纵向、餐次切换通栏、取餐码信息换行）。
